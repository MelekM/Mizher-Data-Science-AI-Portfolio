# Multifamily Development Parcel Optimization

## Overview

This project evaluates multifamily development opportunities using housing and parcel data, exploratory analysis, and linear-programming style optimization. The work is framed around feasibility and decision support rather than pure prediction.

## What It Shows

- operations research applied to a business problem
- optimization thinking grounded in real-estate constraints
- use of parcel, unit, and construction data to support evaluation

## Main Tools

- Python
- PuLP
- spreadsheet-style data preparation
- notebook analysis

## Included Artifacts

- final notebook, HTML export, Python export, and CSV in `Final Files`
- source datasets in `Data`
- project paper in `Paper`
- supporting reference material and process documents
