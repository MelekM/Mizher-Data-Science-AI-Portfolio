# Sentence-Transformer Semantic Chatbot

## Overview

This project builds a retrieval-style chatbot over a specialized stocks-and-bonds corpus using sentence embeddings and cosine similarity instead of rule matching alone.

## What It Shows

- semantic search with dense sentence embeddings
- retrieval-based question answering over a fixed corpus
- practical use of transformer-era NLP models in a lightweight chatbot

## Main Tools

- Python
- `sentence-transformers`
- `multi-qa-MiniLM-L6-cos-v1`
- cosine similarity
