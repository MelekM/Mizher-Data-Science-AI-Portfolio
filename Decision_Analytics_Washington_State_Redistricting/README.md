# Washington State Algorithmic Redistricting

## Overview

This project explores redistricting as an optimization problem, using formal constraints to reorganize districts while balancing population and fairness-related considerations.

## What It Shows

- constraint-based modeling
- geographic and civic problem framing
- analytical translation of qualitative fairness goals into optimization logic

## Main Tools

- Python
- notebook modeling
- decision analytics / operations research methods
