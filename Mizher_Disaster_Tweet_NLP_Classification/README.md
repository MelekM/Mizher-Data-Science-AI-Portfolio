# Disaster Tweet NLP Classification

## Overview

This project tackles short-text classification on disaster-related tweets. The workflow includes text cleaning, tokenization, stop-word removal, lemmatization, and experimentation with both recurrent and transformer-based approaches.

## What It Shows

- end-to-end NLP preprocessing
- sequence modeling with LSTMs
- experimentation with transformer-based components in a Kaggle-style setting

## Main Tools

- Python
- TensorFlow / Keras
- NLTK
- spaCy
- BERT-related experimentation

## Notable Result

The notebook records a best Kaggle submission score of `0.77290`, which makes this one of the stronger public-benchmark NLP projects in the portfolio.
