# The Carbon Footprint of Trade

## Overview

This project investigates emissions embodied in international trade, with a focus on OECD and non-OECD relationships and the policy implications of outsourced carbon impact.

## What It Shows

- analytical storytelling with trade and emissions data
- visual communication for policy-oriented questions
- the ability to package data work into presentation-ready narrative form

## Main Tools

- data visualization workflows
- OECD-style trade analysis
- presentation design

## Included Artifacts

- `EggplantGroup_TheShow_Final.pptx`
- data dictionary and supporting references
- presentation link and additional data/code folders
