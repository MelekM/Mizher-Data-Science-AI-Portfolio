# Walter Chemistry Chatbot

## Overview

Walter is a chemistry-focused chatbot built to answer subject-specific questions in an educational setting. The project emphasizes domain grounding, response logic, and conversational usability instead of generic open-ended chat.

## What It Shows

- Natural language processing in a domain-specific application
- Applied chatbot design for learning support
- Notebook-based prototyping backed by presentation and written explanation

## Main Tools

- Python
- NLP workflows
- chatbot interaction logic
