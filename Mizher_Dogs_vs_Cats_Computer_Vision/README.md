# Dogs vs. Cats Computer Vision Classification

## Overview

This project uses convolutional neural networks to classify dog and cat images. It explores multiple model variants, image resizing strategies, and training workflows to build a binary image-classification pipeline on a benchmark-style dataset.

## What It Shows

- deep learning for image classification
- data preparation for image pipelines
- comparison across CNN model variants

## Main Tools

- Python
- TensorFlow / Keras
- `ImageDataGenerator`
- convolutional neural networks

## Notable Result

One evaluated model variant in the notebook reports approximately `92.01%` accuracy, making this a strong representation of practical CNN experimentation.
