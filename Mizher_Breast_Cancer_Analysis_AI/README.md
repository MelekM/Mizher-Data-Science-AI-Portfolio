# Breast Cancer Malignancy Diagnostics using Neural Networks

## Overview

This project uses the Breast Cancer Wisconsin Diagnostic dataset to compare feature-driven classification approaches and neural-network modeling for malignancy prediction. The work includes exploratory analysis, feature filtering, baseline model comparison, and ROC-style evaluation.

## What It Shows

- Structured-data classification in a medical-style setting
- feature engineering and dimensionality cleanup
- comparison of classical models against neural-network approaches

## Main Tools

- Python
- scikit-learn
- neural networks
- ROC and classifier evaluation

## Included Artifacts

- `Correlation Analysis and Feature Transformation for Breast Cancer Malignancy Diagnostics using Neural Networks.pdf`
- final notebooks and HTML exports in `Python Notebooks and HTML files`
- supporting visual analysis in `Data Analysis` and `Result Visualizations`
- source data and referenced literature
