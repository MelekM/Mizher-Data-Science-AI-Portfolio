# License Plate Recognition using Computer Vision and OCR

## Overview

This folder contains my AI capstone work on automatic license plate recognition. The project combines object detection, image preprocessing, and OCR to localize license plates in real-world vehicle imagery and extract the plate text.

## What It Shows

- Applied computer vision on messy, non-ideal image data
- A detection-first ALPR pipeline rather than OCR in isolation
- Error analysis through saved outputs and confidence-oriented review

## Main Tools

- Python
- YOLOv8
- OpenCV
- OCR workflow and post-processing
